 ⚽ FutbolPro — App de Fútbol Personal

> Aplicación web progresiva (PWA) para futbolistas. Gestiona tus entrenamientos, partidos, estadísticas personales y más.

---

## 📱 Funciones Principales

| # | Función | Descripción |
|---|---------|-------------|
| 1 | **🔐 Inicio de Sesión / Registro** | Autenticación con usuario y contraseña segura |
| 2 | **📅 Calendario de Entrenamientos** | Registra y consulta tus sesiones de práctica |
| 3 | **⚽ Calendario de Partidos** | Historial y resultados de partidos |
| 4 | **📊 Estadísticas Personales** | Goles, asistencias, tarjetas, minutos jugados |
| 5 | **💧 Salud & Recordatorios** | Hidratación, alimentación, sueño |

## 🚀 Cómo usar

### Opción 1 — Abrir directo en el navegador
Descarga `index.html` y ábrelo en cualquier navegador moderno (Chrome, Firefox, Edge, Safari).

### Opción 2 — Netlify (recomendado)
1. Ve a [netlify.com](https://netlify.com) e inicia sesión.
2. Arrastra la carpeta del proyecto al área de deploy.
3. ¡Listo! Netlify genera una URL pública automáticamente.

### Opción 3 — GitHub Pages
1. Sube el proyecto a un repositorio en GitHub.
2. Ve a **Settings → Pages**.
3. Selecciona la rama `main` y carpeta raíz `/`.
4. Guarda; GitHub generará una URL `https://usuario.github.io/futbolpro`.

## 📝 Manual de Usuario Rápido

### Crear cuenta
1. Abre la app y presiona **"Regístrate"**
2. Ingresa tu nombre, correo, posición y contraseña
3. Presiona **"Crear Cuenta"**

### Iniciar sesión
1. Ingresa tu correo y contraseña
2. Presiona **"Iniciar Sesión"**

### Registrar un entrenamiento
1. Ve a la pestaña **Entrenos** 🏃
2. Llena el formulario (nombre, fecha, hora, tipo, notas)
3. Presiona **"Guardar Entrenamiento"**

### Registrar un partido
1. Ve a la pestaña **Partidos** ⚽
2. Ingresa rival, fecha, marcador y tus estadísticas personales
3. Presiona **"Registrar Partido"**

### Ver estadísticas
- Las estadísticas se actualizan automáticamente en la pestaña **Stats** 📊
